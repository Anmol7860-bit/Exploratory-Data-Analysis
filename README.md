# Exploratory Data Analysis
Learning the process of exploratory data analysis (EDA) using Python & Jupyter Notebooks
## 🧠 About  
This repository is a hands-on project by [Anmol7860-bit](https://github.com/Anmol7860-bit) to learn and practice the core steps of exploratory data analysis:  
- Data acquisition & cleaning  
- Statistical summary & distributions  
- Feature correlations & visualisations  
- Dealing with missing values, outliers  
- Generating insights and preparing data for modelling
## 📂 Project Structure 
.
├── EDA.py – A Python script demonstrating EDA workflow
├── Untitled.ipynb – Jupyter Notebook version of the analysis
├── penguins_lter.csv – Sample dataset used (Penguins dataset)
├── .gitattributes

└── README.md – This file
## 🛠️ Getting Started  
### Prerequisites  
Make sure you have the following installed:  
- Python 3.x  
- pip  
- Suggested: virtual environment (venv, conda)  
- Jupyter Notebook (if you’ll run the `.ipynb` file)  

### Installation  
1. Clone this repository:  
   ```bash
   git clone https://github.com/Anmol7860-bit/Exploratory-Data-Analysis.git
   cd Exploratory-Data-Analysis
2.(Optional) Create and activate a virtual environment:   
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
Dataset

📊 dataset used in this project is the Penguins dataset (penguins_lter.csv). This dataset includes measurements for penguin species and is a popular example for exploratory data analysis.
(You can replace or add other datasets as you expand the project.)

📝 Key Learnings

How to inspect and summarise data using pandas (head, describe, info)

Visualising distributions and relationships using seaborn and matplotlib

Identifying and handling missing values and outliers

Understanding feature correlations and basic feature engineering ideas

Preparing data for downstream tasks (e.g., modelling)
